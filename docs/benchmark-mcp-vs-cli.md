# Benchmark：pi 用 AWS MCP + Skills vs AWS CLI 做 AWS 运维任务

- 日期：2026-11-13；账号为一个 PoC 测试账号（账号 ID、成本数据与资源名不公开）；运维区域 us-east-1
- 模型：Bedrock `global.moonshotai.kimi-k3.1`（源区域 sa-east-1），thinking 等级 medium
- 驱动方式：RPC 模式。护栏弹出确认框时，如果每条原因都是"需要 AWS 凭证：…（只读）"，就自动批准（模拟用户点"执行一次"）；否则拒绝。整个 benchmark 中没有出现任何拒绝
- 规模：3 个只读任务，每个跑 1 次（n=1，结果有随机波动，只作为趋势参考）
- 复现：`bash tests/bench/bench.sh all`（详见脚本头注释；结束后运行 `bench.sh clean`）

三种配置：

| 配置 | 安装方式 | AGENTS.md 规则 |
|---|---|---|
| **v1 MCP+Skills** | 默认安装（旧规则） | MCP 优先；官方 aws-agent-rules 要求每个任务先 `search_documentation` + `retrieve_skill` |
| **v2 默认安装（CLI 优先）** | 默认安装（当前规则） | 例行查询用单条只读 `aws` CLI；跨区域 / 批量用 `aws___run_script`；skills 按需加载（见 `templates/ops-rules.md` 的"工具选择"一段） |
| **纯 CLI** | `--no-mcp --no-skills` | 无 |

## 结果

| 任务 | 总 tokens（v1 / v2 / 纯 CLI） | 耗时 秒（v1 / v2 / 纯 CLI） | 费用 USD（v1 / v2 / 纯 CLI） |
|---|---:|---:|---:|
| cost：本月至今按服务成本 Top 5 环比 | 132,128 / 67,878 / 28,428 | 96 / 52 / 41 | 0.293 / 0.159 / 0.110 |
| alarms：us-east-1 中处于 ALARM 的告警 | 150,339 / 24,569 / 8,562 | 64 / 23 / 18 | 0.185 / 0.050 / 0.044 |
| ec2：所有区域 running 实例汇总 | 94,169 / 42,393 / 140,198 | 60 / 51 / 143 | 0.157 / 0.106 / 0.329 |
| **平均** | **125,545 / 44,947 / 59,063** | **73 / 42 / 68** | **0.212 / 0.105 / 0.161** |

三种配置的答案经人工核对，数据一致（成本 Top 5 金额与环比、ALARM 告警与告警总数、各区域 running 实例数）。

v2 和 v1 相比：平均 tokens **-64%**，耗时 **-42%**，费用 **-50%**；和纯 CLI 相比：tokens -24%，耗时 -38%，费用 -35%。v2 在每类任务上都选了合适的工具：cost、alarms 只用了 bash `aws` CLI（分别 4 次、1 次工具调用），ec2 跨全部已启用区域用了 2 次 `aws___run_script`。

## 分析

1. **每轮固定开销**（只发一条 trivial prompt 测得）：纯 CLI 1,346 tokens；v1/v2 默认安装 10,144 tokens。其中 skills 目录描述约 3.7k、MCP 工具定义约 3.3k、AGENTS.md 约 1.8k。这部分随轮数线性增长，但大多命中 prompt cache，所以单个简单任务上 v2 仍比纯 CLI 略贵（alarms 费用 +14%）。
2. **v1 的主要浪费是"每个任务先查 skill"**：alarms 只需一次 API 调用，v1 却多调了 4 次文档 / skill 工具，返回 312 KB，总 tokens 是纯 CLI 的 17.6 倍。v2 在项目规则里覆盖了这一条（官方规则本身声明"与项目指令冲突时以项目指令为准"）。
3. **纯 CLI 在跨区域任务上会退化**：护栏只对单条只读命令免确认，模型逐区域调用了 21 次 `aws`（交互使用时等于用户要点 21 次确认），14 轮、14 万 tokens。v2 遇到这类任务切换到 `aws___run_script`，一次脚本就遍历完所有区域。
4. **CLI 输出更可控**：v2 的 cost 任务工具返回只有 6 KB（纯 CLI 为 96 KB），这得益于规则要求用 `--query` / `--output` 只取需要的字段。

## 结论

- 默认安装采用 **CLI 优先 + MCP 处理跨区域 / 批量 + skills 按需加载**（v2）。
- 环境确实不需要 MCP 时，可以用 `--no-mcp` 省掉约 3.3k tokens/轮，但跨区域任务会退化为逐区域执行 CLI。
- 后续可以再试：`--no-skills` 但保留规则（省约 3.7k tokens/轮），以及 `BENCH_REPEAT=3` 加上 Lambda 排障、安全检查等任务，得到更稳的统计结论。
